Declaración de Accesibilidad

Concorde Transporte Terrestre se compromete a garantizar la accesibilidad digital para personas con discapacidad. Trabajamos continuamente para mejorar la experiencia de todos nuestros usuarios, siguiendo las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1 del World Wide Web Consortium (W3C), nivel AA.

Esta declaración fue revisada el 1 de enero de 2025.

Características implementadas

Navegación por teclado

Todas las funcionalidades son accesibles usando solo el teclado. Incluimos indicadores de foco visibles en todos los elementos interactivos.

Lector de pantalla

Compatible con NVDA, JAWS y VoiceOver. Usamos atributos ARIA, roles semánticos y etiquetas descriptivas.

Contraste de color

Ratio de contraste mínimo de 4.5:1 para texto normal y 3:1 para texto grande, cumpliendo el nivel AA de WCAG.

Diseño responsivo

La interfaz se adapta correctamente a cualquier tamaño de pantalla y permite zoom hasta el 200% sin pérdida de funcionalidad.

Texto alternativo

Todas las imágenes tienen atributos alt descriptivos. Las imágenes decorativas tienen alt="".

Skip links

Enlace "Saltar al contenido principal" al inicio de cada página para usuarios de teclado y lectores de pantalla.
